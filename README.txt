SIROHI GOAT FARM PWA V3

New in V3:
- Farm dashboard with sales, expenses, balance and kids born
- Expense management
- Health next-due dates and dashboard attention alerts
- Breeding kids-born field
- Financial reports
- Improved goat register and search
- Farm profile/location
- Backup and restore
- PWA/offline cache

IMPORTANT:
Data is still stored locally on the device/browser. Cloud login and synchronization are intentionally left for the next stage so the app can first be tested safely on the iPad.

To run as a PWA, host these files on HTTPS and open the site in Safari, then Share > Add to Home Screen.
