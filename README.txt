SIROHI GOAT FARM PWA - VERSION 1

Features:
- Dashboard
- Goat records: Tag, name, type, breed, DOB, weight, notes
- Health records: vaccination, deworming, medicine, illness, check-up
- Breeding records
- Sales records
- Local data storage
- JSON backup
- PWA install support

IMPORTANT:
A service worker/PWA requires HTTPS or localhost. To use it on iPad, upload these files to a hosting service that provides HTTPS.

EASIEST iPad METHOD:
1. Upload the project folder to a web host with HTTPS.
2. Open the website in Safari.
3. Use Share > Add to Home Screen.
4. The app will open like an installed app.

This first version stores records locally in the browser/device. It does not yet have cloud login or multi-device synchronization.
